 ## BabyPhotoshop 🎨

A C++ console-based image processing application developed as an Object-Oriented Programming (OOP) project.
BabyPhotoshop allows users to load, manipulate, and apply various creative filters to images.

---

## 🚀 Features
- **18 Image Filters:** Includes 18 different processing filters (such as grayscale, inversion, merging, flipping, resizing, and color adjustments).
- **Custom Image Class:** Built using a dedicated object-oriented image management structure (`class_image.h`).

---

## 🛠️ Technologies & Libraries
- **Language:** C++
- **IDEs & Tools:** Visual Studio Code (VS Code) / Visual Studio (VS) & Terminal
- **Libraries Used:**
  - `class_image.h`
  - `stb_image.h`
  - `stb_image_write.h`

---

## ⚙️ How to Run
1. Open the project folder in **Visual Studio Code** or **Visual Studio**.
2. Compile the source code using the terminal or IDE build options.
3. Run the executable file.
4. Follow the menu instructions in the terminal to load your image and apply filters.
